# 나라장터 조달 타이쿤 : 달이의 하루

2026 조달청 AI 게임·콘텐츠 공모전 — **AI 게임 부문** 출품작 (개인 참가 · 김재동)

- 라이브 데모: <https://jackdinealkim.github.io/pps-tycoon/>
- 실행: 내려받은 뒤 **`index.html` 더블클릭** (설치·인터넷 연결 없음)

## 무엇을 하는 게임인가

조달청 신임 담당자 '달이'가 되어 하루 다섯 건의 계약을 처리합니다.
요청마다 입찰 후보 세 곳이 제시되고, **규격·납기·정책 태그**를 읽고 한 곳을 고르면
조달 점수·시민 만족·청렴도가 즉시 바뀝니다. 다섯 건을 마치면 조달 등급(S~C)과
오늘 사용한 조달 루트가 정책 카드로 정리됩니다.

플레이 시간 3분 내외 · 키보드 `1` `2` `3` · `Enter`/`Space` · 모바일 터치 · **자동 시연(촬영용)** 모드

## 3D 업그레이드 (Three.js)

- **떠 있는 나라장터 도시(디오라마)** — 절차적으로 생성한 빌딩, 격자 도로, 발광 기단
- **4대 정책 기둥** — `공정 · 혁신 · 민생 · 청렴` 기둥의 높이·발광이 게이지 값에 따라 실시간으로 변합니다
- **홀로그램** — 조달청 로고를 흰색 실루엣으로 그려 띄운 중앙 홀로그램 + 회전 링 + 스캔 광주
- **연출** — 포인터 패럴렉스, 저각/고각 카메라 전환, 컨페티(InstancedMesh), 파동 링, 부유 입자, 드론, 동적 조명
- **결과 화면** — 시상대와 등급 홀로그램(등급 색상 연동), S/A 등급에서 컨페티 버스트
- 마스코트(나르미·달이)는 조달청 공식 아트를 캐릭터별로 분리한 원본만 사용합니다

## 오프라인 실행 (공모전 제출 규격)

심사위원이 ZIP을 풀고 `index.html`을 더블클릭하는 `file://` 환경에서 그대로 동작하도록 만들었습니다.

- 외부 CDN · Google Fonts · `fetch()` · ES module `import` **없음**
- `three.min.js`(r147)와 마스코트/로고 이미지(WebP data URI)를 HTML 안에 **인라인**
- 사운드는 WebAudio 합성음(사용자 클릭 이후 재생)
- 배경음악·폰트·이미지 파일을 따로 받아오지 않습니다

## 파일 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 빌드 결과물(단일 파일, 약 1.4MB) — 배포·제출용 |
| `index_template.html` | 원본 템플릿(`__THREE__`, `__NARMI__`, `__DALL__`, `__LOGO__` 자리표시자) |
| `build.py` | 템플릿 + 벤더 + 이미지를 인라인해 `index.html` 생성 |
| `three.min.js` | Three.js r147 (MIT), 벤더링 |
| `assets/` | 조달청 공식 마스코트·로고에서 분리한 WebP 자산 |

### 다시 빌드하기

```bash
python3 build.py            # index.html 갱신
```
