# 나라장터 조달 타이쿤 : 달이의 하루

2026 조달청 AI 게임·콘텐츠 공모전 AI 게임 부문 출품작입니다.

🎮 **플레이:** https://jackdinealkim.github.io/pps-tycoon/

## 소개

조달청 신임 담당자 '달이'가 되어 하루 다섯 건의 계약을 처리하는 조달 시뮬레이션 게임입니다.
요청마다 입찰 후보 세 곳이 제시되고, 규격·납기·정책 태그를 읽고 한 곳을 고르면
조달 점수·시민 만족·청렴도가 즉시 바뀝니다. 다섯 건을 마치면 조달 등급(S~C)과
오늘 사용한 조달 루트가 정책 카드로 정리됩니다.

- 플레이 시간: 3분 내외 (요청 5건)
- 설치 없음 — `index.html` 하나로 동작하며 인터넷 연결도 필요하지 않습니다.
- 「자동 시연(촬영용)」 버튼으로 시연영상 촬영용 자동 플레이 모드가 있습니다.

## 조작

- 마우스/터치: 후보 카드 클릭
- 키보드: `1` · `2` · `3` 으로 후보 선택

우수조달물품 · 혁신제품 · 중소기업 우선구매(중기간경쟁제품) ·
디지털서비스몰(AI 소프트웨어) · 긴급조달 · 담합 의심 시 재공고
